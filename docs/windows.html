Local AI harness

Run a local AI coding agent on Windows with Strata (beta)

This harness sets up the pi coding agent against a local engine. On Windows the engine is Strata (or gufo): you install and run it with its own tools, and setup.ps1 wires pi to it.

Steps

  1. Install Strata with its own installer and start it. Check it answers: curl.exe -s http://127.0.0.1:8080/v1/models.
  2. Install pi: irm https://pi.dev/install.ps1 | iex.
  3. Get the harness and run the installer. In PowerShell: 
    git clone https://github.com/aic0d3r/local-ai-harness
cd local-ai-harness
powershell -ExecutionPolicy Bypass -File .\setup.ps1
    No Git yet? Download the repo as a ZIP from GitHub, extract it, and run the second command in that folder.
  4. Start pi in your project and pick the Strata model.

What is tested

setup.ps1 is verified on a clean Windows 11 VM against a stub engine. It is not yet verified on Windows hardware with a real Strata. The ./harness wizard, engine launchers and the sidecar are Linux only.
